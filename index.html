🛠 How to add a new dashboard to this page

  1. Place your new dashboard HTML file in the same folder as this index.html.
  2. Open index.html in any text editor (Notepad, VS Code, etc.).
  3. Find the <!-- Add more dashboards below --> comment in the code.
  4. Copy the <a class="dash-card" ...> block, paste it, and update:
    • href="your_file.html" — filename of your new dashboard
    • The icon emoji, name, and description text
    • Change tag-soon to tag-live when it's ready
  5. Save and open index.html in your browser — done!
