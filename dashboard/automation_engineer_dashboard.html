Core knowledge

⚡
MUST
Electrical fundamentals
AC/DC theory, panel wiring, earthing, cable sizing, IP ratings, safety standards
importance 95%
  • Read single-line diagrams and wiring schematics
  • 3-phase power: star/delta, power factor, THD
  • Panel layout: MCB, MCCB, contactors, relays
  • Cable sizing by current, voltage drop, derating
  • Earth fault, short circuit, overload protection
  • IS/IEC/NFPA standards awareness
🖥️
MUST
PLC programming
IEC 61131-3: Ladder, FBD, SFC, ST. Timer/counter/data handling logic
importance 98%
  • Ladder logic: coils, contacts, timers, counters
  • Function Block Diagram (FBD) for complex control
  • Sequential Function Chart (SFC) for state machines
  • Structured Text for data manipulation
  • Analog I/O scaling and signal conditioning
  • Platforms: Mitsubishi, Siemens, Inovance, AB
⚙️
MUST
Drives & motion control
Servo drives, VFDs, encoder feedback, gain tuning, homing routines
importance 92%
  • VFD: V/f, vector control, torque boost
  • Servo: position / speed / torque loop modes
  • Encoder types: incremental, absolute, resolver
  • Auto-tune and manual P/I/D gain adjustment
  • Homing, soft limits, electronic gearing
  • Inovance IS620/SV660N, Siemens S120, Yaskawa
📡
MUST
Sensors & instruments
Proximity, photoelectric, pressure, flow, temperature — selection and wiring
importance 88%
  • PNP vs NPN outputs, sinking/sourcing I/O
  • 4–20 mA and 0–10V analog signal loops
  • Thermocouple vs RTD — types and linearisation
  • Pressure transmitters, flow meters (Coriolis, EM)
  • Encoder and SSI position feedback
  • Sensor noise filtering and debouncing
🔗
MUST
Industrial communication
Modbus RTU/TCP, RS485, CANopen, EtherCAT, PROFIBUS, CANlink
importance 90%
  • Modbus RTU: function codes, register maps, polling
  • RS485 termination, biasing, max nodes
  • CAN bus: bit timing, node IDs, error frames
  • EtherCAT: distributed clocks, topology
  • PROFIBUS DP: GSD files, DP master/slave
  • OPC-UA basics for SCADA connectivity
🖱️
CORE
HMI & SCADA
Screen design, alarms, data logging, trending, remote access
importance 80%
  • HMI screen design: navigation, alarm pages, trends
  • Tag databases and symbol libraries
  • Alarm prioritisation (ISA-18.2)
  • Historical data logging and recipe management
  • SCADA: WinCC, iFIX, InoTouchPad, Ignition
  • Remote access via VPN or web server

Practical skills

MUST
Commissioning
Parameter setup, I/O check, loop tuning, trial runs, handover
importance97%
  • Pre-commissioning: continuity, insulation tests
  • I/O mapping and point-to-point verification
  • Drive and servo parameter upload/backup
  • Loop check: input signal → PLC → output → field
  • Safety circuit: STO, e-stop, guard verification
  • Handover: test certificates, as-built drawings

MUST
Fault diagnosis
Error codes, multimeter, oscilloscope, root cause analysis
importance96%
  • Reading drive fault codes and event logs
  • Multimeter: voltage, continuity, diode test
  • Clamp meter for current measurement
  • Oscilloscope for signal integrity checking
  • Systematic: symptom → cause → verify → fix
  • PCB-level: component identification, SMD testing

CORE
Control theory
PID tuning, closed/open loop, feed-forward, stability analysis
importance82%
  • P, I, D terms: what each does to response
  • Step response analysis: rise time, overshoot, settling
  • Ziegler-Nichols and manual tuning methods
  • Cascade and feed-forward control strategies
  • Anti-windup and bumpless transfer
  • Gain scheduling for nonlinear processes
🧩
MUST
System integration
PLC–drive–HMI–sensor wiring, comms config, end-to-end testing
importance94%
  • Full signal chain: sensor → field cable → panel → PLC
  • Comms network config: baud, node ID, termination
  • I/O mapping: PLC tag ↔ HMI tag ↔ drive register
  • Interlock logic: enable chains, fault acknowledgement
  • EMC: shielding, cable routing, grounding topology
  • FAT and SAT test execution
🦺
MUST
Safety & standards
STO, SIL, LOTO, IEC 61508, machine directive, CE marking
importance93%
  • LOTO procedure: isolate, lock, tag, test, verify
  • STO wiring and verification (IEC 61800-5-2)
  • Safety relay logic: E-stop, two-hand, light curtain
  • Risk assessment: severity × probability matrix
  • SIL levels 1–4 and IEC 61508 functional safety
  • IS/IEC 60204-1 for machine electrical safety
